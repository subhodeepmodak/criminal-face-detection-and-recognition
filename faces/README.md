# Target Face Gallery

Place reference portrait photos of target individuals here.

### Format & Naming Convention
- Supported formats: `.jpg`, `.jpeg`, `.png`
- File naming: The filename (excluding extension) is used as the recognized person's display name.
  - Example: `John_Doe.jpg` -> Displayed as `John_Doe` on detection and alerts.
  - Example: `Suspect_01.png` -> Displayed as `Suspect_01`.

### Best Practices
- Clear, well-lit frontal face portraits yield the best re-identification accuracy.
- Multiple reference photos can be used for the same individual by naming them `Name_1.jpg`, `Name_2.jpg`, etc.
